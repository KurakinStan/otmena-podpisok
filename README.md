# Отмена подписок

Сайт с пошаговыми инструкциями «Как отменить подписку X». Работает на GitHub Pages.
Ведёт пользователей к бесплатному расширению «Трекер подписок» (Chrome Web Store).

## Как устроено

- `tools/content.py` — **все тексты**: список сервисов, шаги отмены, особенности, вопросы.
- `tools/build.py` — сборщик: из `content.py` делает готовые HTML-страницы.
- `assets/` — стили, скрипт поиска, иконки.
- Остальные папки (`kinopoisk/`, `ivi/` и т. д.), `index.html`, `sitemap.xml` — **собираются автоматически**, руками их не правим.

## Как поменять текст

1. Исправить нужный сервис в `tools/content.py`.
2. Запустить `python3 tools/build.py`.
3. Закоммитить и запушить — через 1–2 минуты сайт обновится.

## После покупки домена

1. В `tools/build.py` поменять `SITE_URL` на новый адрес и пересобрать.
2. Добавить файл `CNAME` с доменом и указать домен в Settings → Pages.
